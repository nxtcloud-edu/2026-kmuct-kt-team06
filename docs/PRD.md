## 0. 한 줄

**강의 영상·전사본·슬라이드를 넣으면, 모든 문장에 "몇 강 몇 초"가 붙은 위키가 쌓인다.** 문장을 누르면 그 장면으로 점프하고, 영상은 구간 끝에서 멈춰 그 자리에서 필기를 받는다.

## 1. 문제 정의 (심사 ① — 수치로)

✅ **설문 「강의 녹음·AI 요약 이용 조사」 N=96** (2학년 52 · 4학년 15 · 1학년 14 · 3학년 12 · 기타 3, 국민대 SW·AI학부 외 타교 포함). 원본 `강의 녹음·AI 요약 이용 조사(응답).xlsx`.

| # | 발표에 쓸 숫자 | 근거 |
|---|---|---|
| **1** | **요약 AI를 써 본 학생 75명 중 64명(85%)이 요약을 읽고도 원본으로 되돌아갔다** | 전체 96명 기준 67% |
| 2 | 되돌아간 이유(복수, 64명): 시험에 나올 문장·표현 확인 **59%** · 원본을 봐야 이해됨 **53%** · **AI 요약이 틀린 것 같아서 52%** · 위치(몇 주차·몇 분) 필요 17% | 기타 서술: "원본이랑 교차검증", "내용 빼먹어서", "정확한 용어 확인" |
| 3 | 강의 자료를 요약 AI에 넣어 본 학생 **78%** (75/96) | 이미 다 쓰고 있다 = 시장은 있다 |
| 4 | 이번 학기 강의 녹음 경험 **60%** (58/96) | 입력 데이터를 학생이 이미 갖고 있다 |
| 5 | 시험 기간에 "이게 몇 주차지" 다시 뒤진 시간: 6분 이상 **50%**, 16분 이상 23%(22명), 1시간 이상 7명 | ⚠️ 절반은 0~5분 — **이 숫자는 주장의 중심에 두지 않는다** |

**문제 한 문장**: *"학생 10명 중 8명이 강의를 AI로 요약하지만, 그중 85%는 요약을 못 믿어서 원본을 다시 연다. 요약과 원본 사이에 길이 없기 때문이다."*

⚠️ 정직한 해석: 설문이 지지하는 것은 "시간 낭비"가 아니라 **"요약을 믿을 수 없다 → 원본 확인이 필요하다"**다. 위치 찾기(17%)·뒤진 시간(절반이 5분 이하)은 약하다. 그래서 제품의 중심은 "빨리 찾기"가 아니라 **"모든 문장이 원본으로 가는 길을 갖고 있다(앵커) + 길 없는 문장은 훅이 거부한다"**로 잡는다. 이유 1·2위(문장 확인·원본 이해)는 앵커 클릭 → 그 장면으로 정확히 해결된다.

| 남은 문제 | 지금 학생이 하는 일 |

| 필기가 강의와 따로 논다 | 굿노트 ↔ 녹화본 ↔ PDF를 따로 연다 (설문 문항 없음 — 시연으로 보여 준다) |
| 요약은 쌓이지 않는다 | 강의마다 새 요약 1개, 주차 간 연결 없음 (설문 문항 없음) |

## 2. 사용자와 시나리오

**대상**: 녹화 강의(또는 유튜브 강의)로 복습하는 대학생. 1차 페르소나 = 전공 6과목을 패드로 필기하는 2학년.

**핵심 시나리오 (데모 동선 = 이 순서)**
1. **넣기** — 가진 강의 영상·전사본·슬라이드를 넣는다.
2. **쌓이기** — 에이전트들이 전사본을 구간에 맞추고, 개념 페이지로 컴파일한다. 앵커 없는 문장은 훅이 거부한다.
3. **보기** — 문단 끝 칩을 누르거나 **문장을 드래그 → `원본 보기`** → 그 PPT 슬라이드(또는 프레임) + 영상·녹음의 그 초가 동시에 뜬다.
4. **적기** — 영상이 구간 끝에서 멈춤 → 프레임 옆에 필기 → 저장. 필기에는 코드가 앵커를 붙인다.
5. **자라기** — 강의 1편 → 3편. 페이지·링크 수가 늘고, 같은 개념은 한 페이지로 모인다.
6. **믿기** — 반려 로그(`.history.jsonl`)와 커버리지 N/M으로 "검증이 실제로 돌았다"를 보여준다.

## 3. 왜 에이전트여야 하나 (심사 ②)

- **한 번의 LLM 호출로는 안 된다**: 1시간 전사본(수만 자) → 구간 정렬 → 개념별 승격 → 기존 페이지와 병합 → 검증. 단계마다 읽는 범위·쓰는 권한이 다르다.
- **권한이 다른 7개 역할**: 정렬②은 episodic에 append만, 컴파일③은 concepts/에만, 비평④는 읽기 전용, 사용자👤는 notes/에만. 이걸 프롬프트가 아니라 **코드(훅)로 강제**한다 — AgentGuard(허용 툴 Set) + WritePolicy(쓰기 루트·앵커 존재 확인).
- **모델을 안 믿는 설계**: default deny. 모델은 도구만 부르고, 파일은 훅을 통과한 것만 써진다. 거부되면 이유를 받아 그 문장만 다시 쓴다(자기수정 루프 = 에이전트여야 하는 이유).
- **NotebookLM과의 차이**: 인용은 NotebookLM도 한다. 우리는 ①쌓인다(semantic 페이지 Current/History) ②내 파일이다(마크다운, 옵시디언 호환) ③화면이 점프한다 ④필기가 같은 앵커 체계에 들어온다.

## 4.5 화면 — Quartz 위에 얹는다 (9/20 팀장 결정)

**옵시디언은 오픈소스가 아니다**(무료지만 소스 비공개, 수정·재배포 불가). 그래서 "옵시디언 볼트를 웹으로 내는" 오픈소스 **Quartz 5 (MIT)** 를 쓴다. `wiki/` 는 그대로 옵시디언 볼트로도 열린다.

- **Quartz가 그리는 것**: 위키 본문 · 왼쪽 탐색기 · 검색 · 백링크 · 그래프 · 다크 모드. → 우리는 안 만든다.
- **우리가 얹는 것**: 앵커 칩 · 오른쪽 위 **미니 플레이어**(Aside의 PiP처럼 작게) → 누르면 **split**(위 영상·프레임 / 아래 필기) · 맨 오른쪽 **LLM 패널**(입력창 맨 아래 고정, 답변은 위로 쌓임, Gemini식 입력창 = `＋` · 모델 드롭다운 · 전송).
- **얹는 방법**: Quartz 소스를 고치지 않는다. 서버가 모든 HTML의 `</body>` 앞에 우리 JS/CSS 5줄을 **주입**한다. Quartz는 SPA라 초기화는 `nav` 이벤트에 건다.

✅ **9/20 오전 실측**: Quartz 5.0.0, Node ≥22. `npm ci` 10초 · 빌드 5초(이후 0.5초) · `--watch` 있음 → 파이프라인이 `wiki/` 에 쓰면 몇 초 뒤 화면에 뜬다(= "위키가 자란다" 장면). 주입 서버 `tools/devserve.py` 동작 확인.
⚠️ **실측으로 찾은 함정**: Quartz가 우리 앵커 `[[L3#s5@t=330]]` 를 위키링크로 오해해 `<a class="internal">L3 > s5@t=330</a>` 로 그린다 → `viewer.js` 가 이 패턴의 링크를 앵커 칩으로 바꿔치기한다(CONTRACT §7.2). 파일 속 앵커 규약은 안 바뀐다.
⚠️ 위험: Quartz 5는 나온 지 얼마 안 된 메이저 버전이고 빌드 때 커뮤니티 플러그인을 네트워크로 받는다. EC2에서 0:00에 빌드부터 확인하고, 안 되면 `public/` 을 맥에서 빌드해 올린다.

## 4.6 위키 파일 형식 = 팀장의 옵시디언 노트 형식 (9/20 결정)

강의 노트(`wiki/lectures/`)는 팀장이 실제로 쓰는 형식 그대로: 주제마다 **📄 슬라이드 → 💡 설명 → 🗣 교수님 말 → 🎯 포인트**.
```markdown
> 🗣 "2의 보수는 1학년 때 배웠을 것. 기억 안 나면 **꼭 구글링해서 계산법을 보라.**" [[L3#s17@t=1820]]
> [!youtube] 보충 영상 (정본 아님)
> - [2의 보수 5분 정리](https://www.youtube.com/watch?v=...) — 교수님 채널
```
- **🗣 인용 = 앵커 필수**(훅이 강제). 누르면 교수가 그 말을 한 녹음·영상의 그 초 + 그 슬라이드. 설문 1위 이유 "시험에 나올 문장·표현 확인 59%"에 정확히 대응한다.
- 교수가 선수 지식을 밖으로 넘긴 곳("찾아보라")에만 ③이 `[!youtube]` 콜아웃을 붙인다. 콜아웃 밖 유튜브 링크는 훅이 거부 → 보충 자료가 정본으로 섞이지 않는다.
- 개념 페이지(`wiki/concepts/`)는 Current/History 유지 — 여러 강의에 걸쳐 "쌓이는" 쪽.
- ✅ 훅 실측 6케이스(정상 allow / 🗣 앵커 없음 / 없는 초 / 콜아웃 밖 유튜브 / 📄 앵커 없음 / 쓰기 루트 밖 → REJECTED). Quartz 렌더 확인(앵커 10개, 콜아웃).

## 5. 유튜브 = 보충 추천 (입력 경로 아님 — 9/20 팀장 결정)

LLM 패널은 **위키에만 근거해** 답한다. 그 답변 **아래**에 "관련 영상" 카드 2~3개가 붙는다. **교수님 채널 검색 결과가 먼저**, 그다음 일반 검색. 위키에 근거가 없을 때는 "위키에 근거 없음" + 영상 카드만 나온다 — 모르는 걸 지어내는 대신 볼 곳을 알려 준다.

- 영상은 **앵커가 될 수 없고**, 위키에는 `[!youtube]` 콜아웃으로만 들어간다(§4.6)(signals·notes와 같은 비정본 취급). 정본은 여전히 강의 원본뿐.
- ✅ 저장소 확인: `ZeroPointRepo/youtube-skills`(⭐886, 9/15 푸시) = **TranscriptAPI.com SaaS 래퍼**, 무료 100크레딧 → **HTTP를 `api/` 에서 직접 호출**. `alexmercerind/youtube-search-python` = **2022-06 이후 방치·아카이브 → 안 쓴다.** yt-dlp = README가 "YouTube blocks all major cloud IPs" 명시 → **EC2에서 못 쓴다.**
- 크레딧 방어: 모든 검색 응답을 `raw/.ytcache/` 에 캐시, 발표 질문 3개는 미리 데워 둔다. 실패하면 카드만 빠지고 답변은 나온다.
- API: `GET /api/youtube/search?q=` · `/api/qa` 응답의 `videos[]` (CONTRACT §5.1).

## 6. 모델 — Bedrock 없이

✅ 주최 측: **Bedrock 지원 안 함.** harness v1.1의 "Claude Agent SDK on Bedrock"은 폐기하고, 이미 폴백으로 적어 둔 **"툴 러너 직접 루프"**로 간다. 훅은 우리 파이썬 스크립트를 오케스트레이터가 부르는 구조라 **공급자와 무관**하다.

```python
# pipeline/llm.py — 공급자 어댑터 1개. 에이전트 코드는 이것만 안다
complete(role: "strong"|"fast", system, messages, tools) -> {text, tool_calls}
```
환경변수 `LLM_PROVIDER=openai|anthropic|gemini`, `LLM_STRONG`, `LLM_FAST` 로 바꾼다. 코드 수정 없음.

| 역할 | 하는 일 | OpenAI로 가면 | Claude로 가면 |
|---|---|---|---|
| strong | ③ 컴파일 (긴 입력, 앵커 정확도가 전부) | `o4-mini` 또는 `gpt-5.4-mini` | Sonnet 5 (`claude-sonnet-5`) |
| fast | ②정렬 ④비평 ⑤링커 ⑦QA | `gpt-5.4-nano` / `gpt-4.1-mini` | Haiku 4.5 (`claude-haiku-4-5-20251001`) |

**결정: fast = OpenAI 무료 티어, strong = Sonnet 5(과금 부담되면 o4-mini), Gemini = 패널 선택지.**
- ✅(8/18 확인, 팀장 계정) OpenAI 무료 티어 하루 250만 토큰: gpt-5.4-mini·nano, gpt-5-mini·nano, gpt-4.1-mini·nano, gpt-4o-mini, o3-mini, **o4-mini**. → **비용 0**, 1시간 강의 3편 컴파일에 충분.
- ⚠️ **"gpt-4"(및 gpt-4o·gpt-4.1 본체)는 무료 목록에 없다 → 과금.** 팀이 말한 "gpt-4"는 `gpt-4.1-mini`로 읽는다. "gpt-mini-o4"는 `o4-mini`.
- ⚠️ 무료 티어는 **데이터 공유 조건**으로 보임 → 공개 강의 전사본만 보낸다. 필기(notes)는 컴파일 입력에서 빼거나 Claude 쪽으로만.
- o4-mini는 추론 모델이라 느리다(페이지당 수십 초). 현장 시연은 **미리 컴파일한 결과 + 라이브로 1페이지만**.
- 🆕 **Grok(xAI) API = STT 전용**(9/20 팀장 확정). LLM 공급자가 아니다. ① 적재에서 녹음 → 타임스탬프 전사본. 입력 경로는 둘: **(a) 다글로 전사본(이미 있음, 데모 기본값)** (b) 녹음 업로드 → Grok STT(`pipeline/stt.py`, `XAI_API_KEY`). 둘 다 같은 중간 형식 `raw/L{n}/transcript.json [{t_start, t_end, text}]` 으로 맞춘 뒤 ②로 넘긴다 → ② 이후는 입력이 뭐였는지 모른다. ❓ xAI STT 엔드포인트·타임스탬프 단위·한국어 품질·파일 크기 한도는 현장에서 문서로 확인(미검증). 데모는 (a)로 미리 돌려 두고 (b)는 1분짜리 클립으로 "된다"만 보여 준다.
- 🆕 **Gemini API도 후보**(팀장: 한도는 적지만 쓸 수 있음). 한도가 작으므로 **배치 컴파일에는 쓰지 않고 LLM 패널의 선택지 1개(fast)로만** 둔다 — 429가 나면 어댑터가 OpenAI로 자동 폴백. 정확한 모델명·한도는 키 발급 화면에서 확인 후 `LLM_FAST`에 넣는다(❓).
- ✅ 팀장 확인: **OpenAI·Gemini·Anthropic 키 3종 다 있음.** → 배치 컴파일 strong = Sonnet 5(앵커 정확도 우선) 또는 o4-mini(무료), fast = gpt-5.4-nano(무료). LLM 패널 드롭다운에 3종 노출. 키는 EC2 환경변수로만.

[브라우저]  Quartz 위키 화면 + 주입된 web/viewer (동욱) · web/notes (민수)

     │  모든 쓰기 = AgentGuard → WritePolicy → AuditLog(.history.jsonl)
     ├──▶ pipeline/llm.py ──▶ OpenAI · Anthropic · Gemini   (Bedrock ✗)

## 8. 성공 기준 · 발표 · 리스크

**데모가 성공이려면 (7분 안에 전부 클릭으로)**
1. LLM 패널에 질문 → 앵커 달린 답 + 교수님 채널 영상 카드. 위키에 없는 질문 → "근거 없음" + 영상 카드
2. 문장 클릭 → 영상이 그 초로 간다 — 3문장
3. 구간 끝에서 멈춤 → 필기 저장 → 이어서 재생
4. 일부러 없는 초를 넣어 **422 + 훅 거부 사유**가 화면에 뜬다
5. 대시보드: 강의 1→3편 숫자 증가, 반려 로그 REJECTED 줄, 커버리지 N/M

**발표 7분**: 문제 수치 1분 → 데모 3분 → "왜 에이전트인가" = 훅 레지스트리·쓰기 루트 표·반려 로그 2분 → 한계와 다음 1분.

| 리스크 | 대응 |
|---|---|
| TranscriptAPI 100크레딧 소진·현장 차단 | 데모 3편 사전 캐시 커밋. 검색 실패 시 캐시 목록 |
| 추론 모델이 느림 | 사전 컴파일 + 라이브 1페이지 |
| 프론트 둘이 한 화면에서 충돌 | 이벤트·`#note-slot`·CSS 접두사(CONTRACT §7) |
| Quartz 5가 EC2에서 빌드 안 됨 | 0:00에 확인, 안 되면 맥에서 빌드한 `public/` 업로드 |
| EC2라 yt-dlp 불가 | TranscriptAPI만 사용, 실패 시 카드 생략 |
| 설문이 '시간 낭비'는 약하게 지지 | 주장을 '요약 불신 85%'로 옮김(§1) |
