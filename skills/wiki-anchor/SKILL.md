# 앵커 규약

형식: `[[L{강의}#s{슬라이드}@t={초}]]`
- 예: `[[L3#s12@t=340]]` = 3강 12번 슬라이드, 영상 340초 지점
- 세 요소 모두 필수. `@t`는 정수 초. 범위가 필요하면 `@t=340-372`.
- 앵커는 반드시 `get_source(L, s)`로 존재를 확인한 뒤 쓴다. 추측 금지.

# 페이지 포맷 (semantic 페이지: wiki/concepts/, wiki/lectures/)

```markdown
---
title: <제목>
type: concept | lecture
sources: [L1, L3]        # 근거가 나온 강의 번호
status: draft | approved | grey
updated: YYYY-MM-DD
links: [[다른-페이지]], ...
---

## Current
지금 우리가 믿는 내용. 한 문단 = 한 주장. 각 문단 끝에 앵커 1개 이상.

## History
- YYYY-MM-DD 앵커 [[L3#s12@t=340]] — 이 앵커가 뒷받침하는 주장 한 줄
```

규칙
- Current의 모든 문장은 History의 어떤 줄에 대응돼야 한다.
- History는 append-only. 기존 줄을 지우지 않는다.
- 한 개념 = 한 페이지. 같은 개념이 다른 강의에도 나오면 새 페이지 대신 History에 앵커를 추가한다.

# 강의 노트 포맷 (wiki/lectures/L{n}_<제목>.md) — 2026-09-20 확정, 팀장의 옵시디언 노트 형식

`concepts/` 는 위의 Current/History 를 그대로 쓴다. **`lectures/` 는 아래 형식이다.** 견본: `wiki/lectures/L3_그래프_탐색.md`

```markdown
# L3. <제목>
> 소스: ... · 관련: [[concepts/bfs|BFS]] ...
> 읽는 법: 주제마다 📄 슬라이드 → 💡 설명 → 🗣 교수님 말 → 🎯 포인트

## 1. <주제>
### 📄 슬라이드 (s5~6)
- 슬라이드에 적힌 내용 그대로. 줄마다 끝에 앵커 [[L3#s5@t=330]]
### 💡 설명
- 슬라이드에 없는 맥락·이유. 전사본에서 온 내용이면 앵커를 붙인다
> 🗣 "교수님이 실제로 한 말. 강조는 **굵게**." [[L3#s5@t=320]]
> [!youtube] 보충 영상 (정본 아님)
> - [제목](https://www.youtube.com/watch?v=...) — 교수님 채널 | 검색
### 🎯 포인트
- 시험·이해의 핵심. 교수님이 강조했으면 ★
```

훅이 거부하는 것 (`hooks/write_page_guard.py check_lecture`)
- `## N.` 주제에 `### 📄 슬라이드` 가 없거나, 그 블록에 앵커가 하나도 없음
- `> 🗣` 인용에 앵커가 없음 — **🗣 는 교수가 그 초에 실제로 한 말일 때만 쓴다.** 지어낸 말·요약은 💡 에 쓴다
- 유튜브 링크가 `> [!youtube]` 콜아웃 밖에 있음 — 보충 영상은 정본이 아니다. 앵커로 못 쓴다
- 앵커가 `segments.json` 에 없는 구간을 가리킴

`[!ref]` 레퍼런스 원문 콜아웃: 슬라이드에 **인용 표기**(논문·교재 절)가 있을 때만, 그 📄 블록 바로 아래. `resolve_reference(citation)` 도구가 찾아 준 것만 쓴다(못 찾으면 안 넣는다 — 서지 정보를 지어내지 않는다). 설명은 도구가 준 초록 범위 안에서 1~2문장. 외부 링크는 `[!ref]`·`[!youtube]` 콜아웃 밖에 쓸 수 없다(훅 거부).

`[!youtube]` 는 언제 넣나: 🗣 에서 교수가 **"찾아보라 / 구글링하라 / 1학년 때 배웠을 것"** 처럼 선수 지식을 밖으로 넘겼을 때만. `youtube_search(q)` 도구 결과만 쓴다(교수 채널 결과 먼저). 주제당 최대 2개. 없으면 안 넣는다.
