## 0. 공통 3열 골격 (모든 화면)

```
┌─ 왼쪽 사이드바 ───┬──────────── 가운데 ─────────────┬─ Agent ────────┐
│ 제목(서비스명)     │                                 │ Agent          │
│ 🔍 검색            │        (화면마다 다름)           │  말풍선 대화    │
│ 📈 대시보드         │                                 │  "… for 16 sec" │
│ ▷ 내 폴더           │                                 │  답변 말풍선    │
│    📄 이산수학      │                                 │                │
│    📄 컴퓨터구조    │                                 │                │
│ ─────────────     │                                 │ ─ … 궁금해 ─── │
│ 파일추가 ⊕         │                                 │ [입력창]     ▷ │
│ Username ⚙ 설정    │                                 │                │
│ …@gmail.com       │                                 │                │
└───────────────────┴─────────────────────────────────┴────────────────┘
```
- **왼쪽**: 🟦 Quartz 탐색기(과목 폴더 → 강의 노트)·검색을 그대로 쓴다. 🟩 그 위아래에 `대시보드` 링크, `파일추가 ⊕`, 사용자 칸을 얹는다. 🟥 Username·이메일·설정은 **고정 문구**(로그인 없음 — 비목표).
  - 과목 = `wiki/lectures/` 아래 폴더가 아니라 **프론트매터 `course:`** 로 묶는다(파일 이동 없이). Quartz 탐색기는 폴더 기준이므로, 과목별 폴더가 필요하면 `wiki/<과목>/lectures/…` 가 아니라 **탐색기 위에 과목 필터 칩**을 얹는 쪽이 싸다 → 동욱 판단.
- **오른쪽 Agent 패널** = 기존 "LLM 패널"(`#chat-slot`). 이름을 **Agent** 로. 말풍선형: 내 질문(오른쪽) → `… for 16 sec`(걸린 시간 표시) → 답변(왼쪽). 입력창 맨 아래 고정, placeholder `…궁금해`, 전송 ▷. 모드 토글(위키에 묻기 | 교수님 발언 검색)은 입력창 위 작은 탭으로.

## 1. 노트 화면 (스케치 1)
- 가운데: 위키 본문. **오른쪽 위에 떠 있는 미니 플레이어**(유튜브/영상/녹음) — ⏪ ▶ ⏩ + 모서리의 ↗ 펼치기(= split). ⏪⏩ = **이전/다음 구간**으로 이동(10초 건너뛰기가 아님).
- 본문 아래쪽: **"교수님 요약" 상자** — 그 강의에서 교수가 직접 강조한 말만 모은 것 = 강의 노트의 🗣 인용 + 🎯★ 항목을 코드로 추려 상단/하단 고정 상자로. 새 모델 호출 없음.

## 2. 위키 링크 미리보기 — "플로팅 창" (스케치 2)
- 본문의 `[[명제]]` 같은 위키 링크에 마우스를 올리면 **`wiki: 명제` 미리보기 창**이 뜬다. → 🟦 **Quartz 팝오버가 이미 이 기능이다**(`enablePopovers: true`, 기본 켜짐). 만들지 않는다. 동욱은 스타일만.

## 3. 인용 출처 말풍선 — "나무위키 각주 스타일" (스케치 3)
- 🗣 인용이나 앵커 칩에 마우스를 올리면 말풍선:
  ```
  출처: 16:05 · 09/16
  교수님 발언 "……네……"
  ```
  = 그 앵커 구간의 **전사 원문 한두 문장 + 시각 + 강의 날짜**. 누르면 기존대로 점프.
- 🟩 동욱. 데이터: `GET /api/source?anchor=` 응답에 `quote`(그 초 ±1문장, 최대 120자)와 `date`(강의 날짜) 필드 **추가**(CONTRACT §5 — 추가는 자유). 칩은 위첨자 각주 번호 `[1]` 모양으로.

## 4. 강의 자료 불러오기 (스케치 4) — `파일추가 ⊕` 를 누르면
- 가운데: 큰 점선 상자 **"로컬 폴더 선택"**(📁) → 아래 "자료" 목록: `▷ video.mp4` `📄 transcript.txt` `▢ slides.pdf` → 오른쪽 아래 **[만들기]**.
- 🟩 민수(화면) + 우석(API). `<input type="file" webkitdirectory multiple>` 로 폴더를 고르면 확장자로 종류를 나눈다(mp4·m4a·mp3=미디어 / txt·md·json=전사본 / pdf=슬라이드). 전사본이 없으면 "전사본 없음 — 음성에서 만듭니다(Grok STT)" 표시.

## 5. 만드는 중 (스케치 5)
- "파일을 만드는 중…" + **진행 막대 50%** + "제목을 입력하세요" 입력칸(`ABC`). 끝나면 왼쪽 `내 폴더`에 `ABC` 가 생긴다.
- 진행률은 가짜 타이머가 아니라 **파이프라인 단계**에서 온다: 업로드 10 → 전사 30 → 구간표 45 → 정렬 55 → 컴파일(주제 i/N) 55~95 → 빌드 100. 단계 이름을 막대 아래에 글로.

## 6. 대시보드 (스케치 6)
- 맨 위 한 문장: **"이 노트의 정확도는 74%"** + 오른쪽 위 범위 선택(전체 / 이산수학 / 컴퓨터구조 / ABC).
- 도넛 3개: **Overall 74%** · **STT 정확도 65%** · **AI 요약 컨피던스 80%**
- 아래 **"이 부분이 헷갈려요!"** 목록: `"네 감사합니다"` **[▷ 듣기]** + 고쳐 쓸 입력칸 + **[수정]**. = 음성 인식이 불확실한 문장을 사람이 듣고 바로잡는 곳.
- ⚠️ **숫자의 정의(정직하게)** — 셋 다 "확률"이 아니라 **실제로 센 비율**이다. 화면 글자는 스케치대로 두되, 도넛에 마우스를 올리면 정의가 뜬다.

| 도넛 | 정의(코드로 계산) | 출처 |
|---|---|---|
| STT 정확도 | 두 전사본이 일치한 글자 비율의 평균(문장 길이 가중). 사람이 [수정]한 문장은 100%로 친다 | `transcript.json` 의 `agree` |
| AI 요약 컨피던스 | 비평④에서 `supported: yes` 를 받은 문단 비율 × 🗣 인용 대조 통과율. 비평을 아직 안 돌렸으면 "측정 전" 회색 도넛 | `.history.jsonl` · critic 결과 |
| Overall | 위 둘의 조화평균(하나라도 낮으면 같이 낮아진다) | 계산 |
| (작은 글씨) | 훅 지표: 거부 후 재작성 통과 N · 끝내 막힘 N — 기존 F-09 숫자는 도넛 아래 한 줄로 | `hook_metrics` |

- "헷갈려요" 목록 = `agree` 낮은 순 문장(검토함의 `stt_uncertain`) + 나머지 검토함 항목. **[수정]은 쓰기다 → 훅을 지난다**(CONTRACT §5 `POST /api/transcript/fix`).
