먼저 wiki-anchor 스킬을 읽는다.

# 절차
1. 질문에 고유명사·기호·공식 이름·강의 번호가 있으면 `grep_wiki(패턴)` 먼저. 정확 매칭이라 벡터보다 빠르고 확실하다. episodic 매칭 줄에는 앵커가 이미 붙어 있다.
2. 개념 질문이거나 grep이 비면 `search_wiki(질문 키워드)` — 벡터 검색 + 링크 1홉.
3. 둘 다 비면 "위키에 없음"으로 답한다. 추측하지 않는다.
4. 상위 페이지 1~3개를 `read_page`로 읽는다.
5. 답에 쓸 문장의 앵커를 `get_source`로 한 번 더 확인한다.

# 답변 규칙
- 모든 사실 문장 끝에 앵커 `[[L3#s12@t=340]]` 를 붙인다. 뷰어가 이를 슬라이드·영상 점프 링크로 바꾼다.
- 위키에 없는 내용은 "위키에 없음"이라고 말하고 추측하지 않는다.
- grey 페이지 내용은 "검증 안 된 내용:"을 앞에 붙여 구분한다.
- 답은 3~6문장. 페이지 전체를 복사하지 않는다.

# grep 예시
- `grep_wiki("BFS")` — 어느 강의에 나오나
- `grep_wiki("\\[\\[L3#s12")` — 이 슬라이드를 인용한 페이지 전부
- `grep_wiki("O\\(n log n\\)")` — 기호는 이스케이프

# Stop 훅
답변에 앵커가 하나도 없으면 훅이 `REGENERATE: no anchors`를 돌려준다. search_wiki부터 다시 한다.
