## 3. 설계와 달라진 곳
1. **뷰어는 Quartz 위 오버레이가 아니라 독립 SPA**(`web/viewer/viewer.js`)다. 페이지 목록을 JSON 으로 읽는다 → `tools/build_library.py` 가 `wiki/` 로 `web/viewer/library.local.json`(gitignore)을 만들고, 없으면 커밋된 견본 `library.json` 으로 폴백. `build_wiki` 가 빌드 때마다 같이 돌린다.
2. **샘플(mock) 모드 기본값 = 꺼짐**. 켜져 있으면 채팅이 가짜 답을 내고 앵커 클릭이 재생을 안 한다(`if (!state.mock)`).
3. **미디어 메타**: `api/media.json`(커밋, 과목·날짜·미디어 종류) + `raw/media.local.json`(🚧 업로드 시 서버가 쓰는 오버레이). 미디어 파일이 실제로 없으면 `/api/source` 의 `video` 는 `null` → 뷰어는 슬라이드·발언만 보여준다.
4. **숨기기 = 서버 상태**. 뷰어의 🗑 → `POST /api/review/hide`(프론트매터 `status: grey`, user 권한으로 훅 통과·history 기록) → Quartz 빌드에서 제외, 뷰어 목록에는 남아 휴지통에서 `POST /api/review/approve` 로 복원. ✅ 브라우저 왕복 실측.
5. **비평은 판정만**. suspended/partial 을 검토함에 올릴 뿐 페이지를 자동 강등하지 않는다(자동 grey 강등으로 13쪽 중 8쪽이 사라졌던 버그).
6. **발언 검색 결과**에 `agree`(전사 일치율|null)·`course` 추가(SPEC F-01 AC4).
7. 🚧 **적재 ① 자동화**(`pipeline/prep.py`): 업로드된 PDF·전사본·녹음 → 슬라이드 PNG·`book.md`·`segments.json`·`L{n}.mp4`. 전사본이 없으면 Grok STT. 오늘 네 강의는 같은 절차를 사람이 손으로 했다.
8. 🚧 **강의 1편 = 노트 1개**. 컴파일을 주제마다 따로 불러 제목을 매번 새로 지은 탓에 강의가 주제별 파일 3~6개로 쪼개졌다 → `tools/merge_lecture_notes.py`(코드, 본문·앵커 불변, 훅 통과)로 합치고, 앞으로는 파일 경로를 코드가 고정한다.
