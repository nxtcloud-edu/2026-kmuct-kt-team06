# MOTGA 프론트엔드

```powershell
python web/viewer/serve.py 8000
```

브라우저에서 http://localhost:8000 을 엽니다. Node 설치나 Quartz 빌드 없이 실행됩니다. 서버 시작 시 `wiki/lectures`, `wiki/concepts`를 읽어 `library.json`을 갱신합니다. 기존 `tools/devserve.py`에서는 `/web/viewer/`로 접속할 수 있습니다.

첨부 스케치의 왼쪽 라이브러리 · 가운데 노트/검색/업로드/대시보드 · 오른쪽 Agent 구조를 구현했습니다. 원본 칩과 문장 선택 → 원본 보기, 구간 필기 저장, 자료 드롭/선택, 텍스트 읽기 진행률, 로컬 노트 생성, 검토 승인, 교수님 발언 검색을 지원합니다.

- 기본은 **샘플 모드**입니다. QA 샘플은 BFS 질문에만 고정 답변을 표시하고 그 외 질문에는 근거 없음 결과를 표시합니다. 가짜 샘플 영상 링크는 클릭되지 않습니다.
- 왼쪽 하단 프로필 설정에서 샘플 모드를 끄면 CONTRACT의 `/api` 주소를 사용합니다. API 서버는 이 저장소에 아직 없습니다. 오류 응답은 화면에 표시합니다.
- 로컬 필기·검토 상태·가져온 텍스트는 `localStorage`에 보관합니다. 영상 파일은 현재 탭에서만 유지되며, 서버로 업로드하지 않습니다. 실제 AI 전사/노트 생성 API가 없으므로 자료 생성 화면은 **실제 파일 읽기 진행률**만 표시합니다.
- 샘플 원본 영상은 저장소에 없습니다. 앵커 클릭 시 구간표로 시간 유효성을 확인하고 해당 샘플 프레임을 표시합니다. 실제 API의 MP4/audio는 시간 이동과 구간 끝 정지를 지원합니다. YouTube는 해당 시간의 새 탭 링크를 제공합니다.
- 대시보드 도넛은 추정 정확도 대신 실제 샘플 수치의 커버리지, 검토 완료 비율, 첫 검증 통과 비율을 표시합니다.
- Quartz 소스, API 스키마, 기존 데이터는 변경하지 않습니다. 주입 스크립트 파일명과 공용 이벤트를 유지하며 독립 앱 레이아웃을 마운트합니다.

키보드: `Ctrl/Cmd K` 검색, `Enter` 질문 전송, `Shift Enter` 줄바꿈. 좁은 화면에서는 메뉴와 Agent를 접어서 사용할 수 있습니다.

## 브라우저 검증

위 서버를 실행하고 Chrome이 설치된 환경에서:

```powershell
cd web/viewer/tests
npm.cmd install
npm.cmd test
```

`smoke.cjs`는 실제 클릭으로 검색, 앵커, 개념 미리보기, 선택한 문장에서 원본 열기, 필기 보존, 대시보드, 검토 승인, QA, 발언 검색, 파일 입력, 안전한 텍스트 렌더링, 모바일을 검사합니다. `api.cjs`는 가로챈 API 응답과 실제 WAV 재생으로 구간 정지·재개 및 401/422/500 오류를 검사합니다. 실제 백엔드를 실행한 통합 테스트와는 구분됩니다. 스크린샷은 `tests/desktop.png`, `dashboard.png`, `mobile.png`에 생성됩니다.
